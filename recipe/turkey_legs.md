## Ingredients

|  Amount | Ingredient                                    | Brand                                         |
| ------: | --------------------------------------------- | --------------------------------------------- |
|  0.5 oz | Fresh Lime Juice                              |                                               |
|    1 oz | Applejack                                     | Laird’s Straight Apple Brandy Bottled in Bond |
|  0.5 oz | [Honey Syrup]({%link recipe/honey_syrup.md%}) |                                               |
| 0.75 oz | Allspice Dram                                 | St. Elizabeth                                 |
|  0.5 oz | Dark Rum                                      |                                               |

## Notes

- Method: Build in the Glass
- Pour: Add all ingredients directly to the glass
- Glassware:
  - High Ball glass
  - Crushed Ice
- Garnish: mint
- Special Prep: 
  - Add all ingredients, but the rum, to the glass.
  - Add crushed ice.
  - Stir vigorously (swizzle) to combine. 
  - Top with additional crushed ice. 
  - Float the dark rum on top.
