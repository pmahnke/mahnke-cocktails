## Ingredients

|  Amount | Ingredient                                               | Brand                  |
| ------: | -------------------------------------------------------- | ---------------------- |
| 0.75 oz | Cognac                                                   | Planat                 |
| 0.75 oz | Rhum Agricole                                            | Barbancourt 3 Star Rum |
| 0.25 oz | Rhum Agricole                                            | Clément                |
| 0.75 oz | Banana Liqueur                                           | Giffard                |
| 0.25 oz | [Rich Demerara Syrup]({%link recipe/demerara_syrup.md%}) |                        |
| 0.75 oz | Fresh lime juice                                         |                        |

## Notes

- Method: Shaken
- Pour: Open Pour
- Glassware:
  - Low Ball glass
  - Crushed Ice
- Garnish: lime shell, mint
- Special Prep: Squeeze a lime wedge and add it to the shaking tin, then build the cocktail on top
